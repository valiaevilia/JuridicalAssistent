# Offline-проверки роли L — 14.11.2026

Среда: Windows, Python 3.13.15. Настоящий клиент моделей, ключ и поиск не используются.

| Проверка | Результат |
|---|---|
| `python -X utf8 -m unittest discover -s tests -v` | 69 тестов, OK, без пропусков |
| Ручные сценарии 18 демо внутри `test_demo_scenarios` | Пройдены с предзаданными S6/S8; не оценка настоящей LLM |
| `python -X utf8 -m examples.offline_demo` | `answered`, 3 вызова тестового клиента, каноническая ссылка |
| Тот же пример через `python -S` | Работает без site-packages, включая PyYAML |
| `examples.verify_materials --data-dir ...` | 20 выдержек совпали с исходниками; 18 вопросов разобраны |
| Исходный архив | 21 документ; подтверждены инъекция ЮО-7 и наличие ТК ст. 152 |
| `requirements.txt` | Побайтное совпадение с разрешённым списком организаторов |
| AST пяти корневых модулей с `feature_version=(3,11)` | Совместимый синтаксис Python 3.11; выполнение проверялось на 3.13 |

Проверяются C1–C10, отсутствие неявного тестового клиента, подделка истории,
потеря условий при короткой цитате, неизвестные ссылки и пункты, подмена чисел
и единиц, обязательные оговорки, частичная выдача, JSON и его обрезка,
ограничение повторов, ошибки клиента, S8/S9 с повторной проверкой, общий счётчик
вызовов и дедлайн, выдача при исчерпанном бюджете, лимит текста и HTTP-адаптер.
В интеграционных тестах соединения через socket блокируются.

Для реальной DeepSeek V4.1 Flash пока не измерены: качество 18 демо-ответов,
MatchRate/WinRate, fabricated_rate, false_refusal_rate, устойчивость ко всем
инъекциям, качество S1/S8, абляции и время полного сабмита. Результаты сценариев
с ScriptedLLM не следует выдавать за эти метрики. Отдельный вебинар недоступен;
его пересказ в командном плане не заменяет официальный источник.
